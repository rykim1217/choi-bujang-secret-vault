# 라요 · 처음 실행하기

**준비:** Windows와 Node.js 24.19.0이 필요합니다. Node.js가 없다면 [공식 사이트](https://nodejs.org/)에서 설치한 뒤 진행하세요. 관리자 권한은 필요 없습니다.

## 1. 폴더 열기

받은 프로젝트의 **on-client** 폴더를 엽니다. `package.json`이 보여야 합니다.
파일 탐색기 주소 표시줄에 `powershell`을 입력하고 Enter를 누르세요.

## 2. 실행하기

아래 명령을 입력합니다. 실행 창은 닫지 마세요.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1
```

## 3. 앱 열기

계정 연결 준비 완료와 시작 메시지가 나오면 브라우저에서 **http://127.0.0.1:5189/** 을 엽니다.

- **보호 현황 → 학생 구현 표시 → 내 PC 상태:** CPU·메모리·디스크 실제 값과 측정 시각 확인
- **같은 학생 영역의 연결·Windows 기록:** 「다시 조회」를 누르고 결과 확인

상단의 **연결 없음·SDP 미연결**은 기존 서버 연동 상태입니다. PC 자체 조회와는 별개입니다. 읽지 못한 값은 확인 불가로 표시하고, Windows 경고·오류 건수는 공격 탐지 결과가 아닙니다.

## 4. 종료하기

실행 창에서 **Ctrl+C**를 누릅니다. 종료 확인이 나오면 Y를 입력하세요.
다시 켤 때는 같은 폴더에서 2번 명령을 실행합니다.

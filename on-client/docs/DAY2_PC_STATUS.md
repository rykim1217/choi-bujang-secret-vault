# 2일차 · 내 PC 실제 측정

기존 제공 기능은 계정·기기 보안 상태, 세션, 업무 앱, 보안 기록입니다. CPU·메모리·디스크 사용량 측정은 제공 코드에 없어서 student/pc-* 파일로 추가했습니다. 제공 서버·public/app.js·인증·판정 코드는 변경하지 않았습니다. 기본 보안 데이터 연결은 여전히 별도 설정이 필요합니다.

## 실행과 확인

기존 on-client 폴더에서 Node.js 24.19.0으로 실행합니다.

```powershell
npm run check
npm run start:pc
```

1. http://127.0.0.1:5190/ 을 엽니다. 기존 5189 서버와 동시에 사용할 수 있습니다.
2. 맨 위 내 PC 상태에서 CPU, 메모리, 시스템 드라이브 남은 공간과 각 측정 시각을 확인합니다.
3. 지금 측정을 다시 누르면 직전 값 비교, 추이와 기록이 추가됩니다.
4. 작업 관리자 성능 탭과 비교합니다. CPU는 약 1초 전체 CPU 평균입니다. 메모리는 전체 물리 메모리에서 여유 메모리를 뺍니다. GB는 10진 단위로 표시하므로 Windows의 표시 단위나 메모리 분류, 측정 시점에 따라 차이가 날 수 있습니다.
5. 네트워크 연결을 끊거나 서버를 종료한 뒤 측정하면 확인 불가가 표시되는지 확인합니다. 브라우저에 이전 값이 현재 값으로 남아 있지 않아야 합니다.
6. 종료는 실행 창에서 Ctrl+C, 재실행은 같은 명령입니다. 기록은 화면을 연 동안 최대 30회만 보관하며 새로고침하면 초기화됩니다.

## 측정 근거와 제한

- CPU: node:os cpus()의 누적 카운터를 약 1초 간격으로 두 번 읽어 idle/total 차이로 계산합니다.
- 메모리: node:os totalmem()/freemem(), 단위 bytes를 GB·%로 변환합니다.
- 디스크: node:fs/promises statfs()를 시스템 드라이브에 호출합니다. 일반 사용자에게 사용 가능한 bavail 공간입니다.
- 모두 서버가 실행되는 PC의 실제 값이며 외부 전송·관리자 권한·유료 AI 요청을 사용하지 않습니다. 예시 데이터는 사용하지 않습니다.
- 항목별 실패는 unknown과 이유·조회 시각으로 반환합니다. 실패값은 그래프에서 제외하고 연결선을 끊습니다.
- 최초 한 번 자동 측정하고 이후 버튼을 누를 때만 측정합니다. 주기적 수집이나 기록 영구 저장은 하지 않습니다.
- 추가 비교 기능: 직전 측정 대비 CPU %p, 메모리 사용 GB, 디스크 여유 GB 변화입니다.
- package-app과 바탕화면 바로가기는 이후 포장 단계의 작업이며 아직 구현하지 않았습니다.

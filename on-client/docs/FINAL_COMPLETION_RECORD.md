## 3. 값의 종류 구분

- 실제 조회: Node OS/파일 시스템 API의 CPU·메모리·디스크 정보, PowerShell 읽기 전용 Windows 명령의 네트워크·방화벽·이벤트 결과. 항목별 출처와 조회 시각을 표시합니다.
- 설명용 예시: 추가한 PC 대시보드에는 사용하지 않습니다. 수업 페이지의 그림은 설명용 예시입니다. 기존 npm run demo는 별도 연습 자료이며 실제 연결 성공이 아닙니다.
- 미연결: 현재 PC 서버 실행 경로에 실제 SDP 호스트가 구성되지 않아 SDP 미연결. 기존 보호 현황·업무 앱·보안 기록의 실제 서버 연동도 성공으로 확인하지 않았습니다.
- 확인 불가: 권한·지원·제한 시간·서버 응답 실패 등 읽을 수 없는 경우. 실패 이유와 조회 시각·다음 행동을 안내하며 예시로 대체하지 않습니다.

### 시연 순서 · 아직 전체 연습 완료로 기록하지 않음

1. 앱 실행 후 내 PC 상태에서 실제 값·단위·시각을 보여 줍니다. 다시 조회로 비교·추이·기록을 확인합니다.

4. 실행 제한과 실제 확인 범위를 말하고 종료·재실행합니다. 아직 수행하지 않았다면 연습 결과는 미확인으로 남깁니다.

## 7. 외부 SaaS를 쓴 경우에만

## 8. 남은 한계와 다음에 확인할 것

- 실제 SDP·기존 보안 서버·AI 연결은 미확인 또는 미연결. 기존 기능 전체가 완성됐다고 표현하지 않습니다.
- package-app 명령 없음으로 공식 포장·INSTALL.md·manifest·승인 host 바로가기 검증 미실시. 최신 안내에 따라 포장 생략.
- 사용자의 PC와 다른 PC에서 전체 기능이 같게 동작하는지는 미확인. Windows 정책·권한에 따라 확인 불가가 나올 수 있습니다.
- 측정·조회 기록은 화면 메모리에만 보관하며 새로고침 시 초기화됩니다. 자동 공격 탐지·상시 모니터링 기능이 아닙니다.
- 다음 확인: 위 시연 순서대로 사용자 전체 연습, 이 문서를 포함한 최종 커밋 저장, GitHub에 올린 커밋과 로컬 커밋 일치 확인, 실제 과제의 저장소 주소·40자리 커밋 제출. 아직 push나 제출하지 않았습니다.

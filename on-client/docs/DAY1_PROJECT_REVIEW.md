## 기존 프로젝트와 선택한 작전

- 앱 이름: 라요.
- 기존 프로젝트의 on-client 폴더에서 실행했습니다. 새 프로젝트를 만들지 않았습니다.
- 화면 틀: 관제 대시보드형. 상단 상태 카드 네 개, 아래 추이와 기록.
- 포장 형태: 기본 포장과 바로가기. package-app 구현과 포장 검증은 이후 단계의 작업입니다.
- 기존 프로젝트·제출물은 삭제하거나 이동하지 않았습니다. 1일차에는 파일을 수정하지 않았습니다.

## 당시 확인한 실행 방법

기존 프로젝트의 on-client 폴더에서 다음을 실행했습니다.

```powershell
npm run check
npm start
```

당시 기존 화면 주소는 http://127.0.0.1:5189/ 입니다. 종료는 실행 창에서 Ctrl+C입니다. 현재 추가한 PC 대시보드를 실행하려면 2일차 이후의 `npm.cmd run start:pc`와 기본 주소 5190을 사용합니다. 처음 실행하는 사람은 현재 안내인 [START_HERE.md](START_HERE.md)를 따릅니다.

## 당시 추천한 핵심 기능 세 가지

1. 보안 상태 요약: 기기·세션·접근 판정·연결 상태를 알기 쉽게 표시.
2. 보안 기록 보기: 최근 기록·필터·상세 근거 확인.
3. 주의·확인 불가 안내: 조회 실패를 정상과 구분하고 이유와 다음 행동 제시.

위 내용은 당시 대화에서 제안한 기능 방향입니다. 이후 2·3일차 과제에 따라 실제 PC 사용량, 네트워크 구성·방화벽 설정·Windows 기록을 추가했습니다. 기존 서버 연동 기능은 로컬 PC 조회와 별개이며, 해당 기능의 실연결 성공을 주장하지 않습니다.
